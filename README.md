# Floral Photography

A simple photography portfolio website where visitors can upload flower photos, like them, and leave comments.

## Live Demo

Once hosted on GitHub Pages, your site will be live at:
`https://inderj166.github.io/floral-photography/`

## Features

- Upload photos directly from the browser
- Add a caption to each photo
- Like/unlike photos
- Leave comments on any photo
- Scrolling welcome banner

## Important Note on Data

This is a static website (no backend server or database). That means:
- Photos, likes, and comments are saved only in **your own browser's local storage**
- Other visitors to your site will **not** see photos you upload, or vice versa
- Clearing your browser data will remove everything

If you want a shared gallery where everyone sees the same photos, likes, and comments, this would need to be connected to a backend service (such as Firebase or Supabase) — let me know if you'd like help setting that up.

## How to Run Locally

Just open `index.html` in any web browser — no installation needed.

## How to Host on GitHub Pages (Free)

1. Create a new repo (e.g. `floral-photography`) and upload `index.html` and this `README.md`
2. Go to **Settings → Pages**
3. Under "Source," select the `main` branch and `/ (root)` folder
4. Save — your site will be live at `https://inderj166.github.io/floral-photography/` within a minute or two
