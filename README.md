# Floral Photography

A simple photography portfolio website where visitors can upload flower photos, like them, and leave comments.

## Live Demo

Once hosted on GitHub Pages, site will be live at: <br>
(https://inderj166.github.io/first-website-project/)

## Features

- Upload photos directly from the browser
- Add a caption to each photo
- Like/unlike photos
- Leave comments on any photo
- Scrolling welcome banner
